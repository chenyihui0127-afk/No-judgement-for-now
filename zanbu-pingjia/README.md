# 暂不评价

一个情绪体验型网页原型：让普通人暂时退出自我考核。

## 功能
- 首页与响应式布局
- 六类状态选择及对应回信
- 复制回信
- 陌生人留言墙（包含示例内容）
- 提交匿名留言的交互演示
- 本地浏览器保存用户留言（localStorage）

## 本地运行
直接用浏览器打开 `index.html` 即可。无需安装依赖或启动服务器。

## 当前原型的限制
- 用户提交的留言仅保存于当前浏览器，不会上传或公开展示。
- 留言墙示例是演示内容，不代表真实用户投稿。
- 点亮按钮仅为前端交互，不会跨设备同步。
- 正式上线前应接入后端数据库、内容审核、滥用防护、删除机制与隐私说明。

## 部署
可以将 `index.html` 部署到 GitHub Pages、Netlify 或 Vercel 等静态托管服务。若要实现真正的跨用户匿名留言，需要增加后端服务。
